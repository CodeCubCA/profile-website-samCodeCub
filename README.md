# 🌐 Personal Portfolio Website

A dynamic and interactive portfolio website showcasing my journey as a student, developer, and creator.

## 📖 About

This is my personal portfolio website built from scratch using vanilla HTML5, CSS3, and JavaScript. The site features an interactive design with three custom-built HTML5 Canvas games including Neon Snake Arena, Royal Tower Defense, and Brawl Stars Arena. It demonstrates my skills in web development, game mechanics, animations, and responsive design while sharing my academic projects and achievements.

## ✨ Features

- **Interactive Profile Card** - Dynamic profile section with status indicators and social links
- **Project Showcase** - Beautifully designed project cards highlighting my work including academic projects and coding endeavors
- **Three Custom HTML5 Canvas Games**:
  - 🐍 **Neon Snake Arena** - Classic snake game with particle effects, power-ups, and neon glow effects
  - ⚔️ **Royal Tower Defense** - Real-time tower defense with strategic card-based gameplay and AI opponent
  - ⭐ **Brawl Stars Arena** - Action-packed battle arena with combat systems, gem collection, and multiple enemy types
- **Skills Section** - Visual representation of academic skills and interests with animated progress bars
- **Responsive Design** - Fully optimized for desktop, tablet, and mobile devices
- **Modern UI/UX** - Clean, professional design with gradient effects, smooth transitions, and hover animations
- **Featured Projects**:
  - Portfolio Website with advanced game mechanics
  - Study Buddy AI Assistant powered by Groq API

## 🛠️ Technologies Used

- **HTML5** - Semantic markup and Canvas API for game development
- **CSS3** - Modern styling with gradients, animations, flexbox, and grid layouts
- **JavaScript** - Vanilla JS for game logic, DOM manipulation, and interactivity
- **Canvas API** - For rendering games and animations
- **Git & GitHub** - Version control and deployment

## 🚀 How to Run Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/CodeCubCA/profile-website-samCodeCub.git
   cd profile-website-samCodeCub
   ```

2. **Open in browser**
   ```bash
   # Simply open the index.html file in your preferred browser
   open profile/index.html
   # Or on Windows
   start profile/index.html
   # Or on Linux
   xdg-open profile/index.html
   ```

3. **Alternative: Use a local server (recommended)**
   ```bash
   # If you have Python installed
   cd profile
   python -m http.server 8000
   # Then visit http://localhost:8000 in your browser
   ```
